# B站首页 AI/低质视频标记

在 B 站首页把疑似 AI 生成或批量搬运的低质视频**整卡变淡到 30%**，鼠标移上去立即恢复。不改排版，不加标签和弹窗。

## 使用效果

- 检测中：卡片右下角小放大镜轻微摆动，通常几秒后消失。
- 判定疑似：整卡变淡，悬停恢复，移开重新变淡。
- 其它卡片：与 B 站原样一致。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Edge / Chrome 扩展商店可搜到）。
2. 点此安装脚本：
   https://raw.githubusercontent.com/SinCircle/bili-ai-filter/main/bili-ai-filter.user.js
   弹出安装页后点「安装」。
3. 打开 https://www.bilibili.com/ 并刷新。

装不上时，可在 Tampermonkey 新建脚本，粘贴 `bili-ai-filter.user.js` 内容保存。

## 判定依据

综合 B 站公开信息和视频数据打分，多个信号同时出现才变淡：

| 类别 | 看什么 |
|---|---|
| UP 主 | 粉丝少、账号新、近期投稿频率高、无认证 |
| 标题简介 | AIGC、AI 教程、即梦、可灵等工具名，或“免费领取”“变现”等营销词 |
| 传播方式 | 多个不同 UP 发布同一标题（矩阵号） |
| 视频本身 | 官方 AI 声明、赞播比异常、时长异常 |

单一信号不会触发；正常新人 UP 一般不会误伤。

## 菜单

Tampermonkey 图标菜单可暂停/恢复标记、清除缓存、重新扫描当前页。

## 已知限制

- 只对首页推荐生效。
- 需请求 B 站接口，卡片多时要等几秒。
- B 站改版可能失效，需等更新。
- 判定是概率性的，可能漏判或误判，仅供参考。

## 隐私

只访问 B 站自己的接口，使用当前登录状态；结果只缓存在 Tampermonkey 本地，不上传任何数据。
